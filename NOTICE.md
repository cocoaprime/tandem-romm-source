## Dated changes in this fork

- **16 November 2026:** added optional RoMM 5.4.1 settings, token-based
  authentication, a connection test, and remote library browsing with metadata and artwork.
- **17 November 2026:** added downloads into local platform folders, destination
  selection, metadata and cover import, and integration with Tandem's Home library.
- **18 November 2026:** added parallel and background downloads, support for
  multi-file games across compatible platforms, and local-first Home search and ordering.

- **18 November 2026:** updated the GitHub release feed for this fork and added
  support for the stable `Tandem-RoMM.apk` asset name.
